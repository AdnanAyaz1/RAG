# Project Vision

Build a centralized platform that allows hospitals to onboard, verify, manage, and monitor healthcare vendors from a single system.

---

# Business Problem

The client currently manages vendors using spreadsheets, emails, and paper documents.

This causes:

- Slow onboarding
- Missing compliance documents
- Duplicate vendor records
- Poor visibility into vendor status

---

# Business Goals

- Reduce vendor onboarding time by 70%.
- Centralize vendor information.
- Automate compliance tracking.
- Improve reporting for administrators.

---

# Success Criteria

- Vendors can self-register.
- Administrators can review and approve vendors.
- Compliance documents can be uploaded and tracked.
- Reports are available through a dashboard.

---

# Target Users

| User Type | Description |
|-----------|-------------|
| Vendor | Registers and manages company information |
